# Better BigBig Won Assistant

BIGBIG WON 手柄的第三方配置工具。纯 WebHID，浏览器直连，免驱动、免安装官方软件。

仓库包含两部分：`bbw-protocol/` 是协议库（分帧、CRC、字段解析与序列化），`bbw-webui/` 是基于它做的网页控制台。协议由分析官方配置工具的 USB 通信与静态逆向得到，关键结论都在真机上核对过。

## 支持的设备

| 项目 | 值 |
|---|---|
| 开发与验证型号 | 墨将彩虹 3（BIGBIG WON RAINBOW 3） |
| VID / PID | `0x413D` / `0x2104` |
| 配置通道 | MI_02，`usagePage 0xFF7A`，64 字节报告 |
| 游戏输入通道 | IG_00，15 字节输入报告 |

其他墨将型号不保证兼容。字段表以彩虹 3 实测为准，换型号前请先读取配置确认解析正常，并做好备份。

## 使用

```sh
cd bbw-webui
npm install
npm run build
npm run serve          # http://127.0.0.1:8123/
```

需要 Chrome 或 Edge 89+（WebHID）。官方助手会独占设备，连接前请先退出。

打开页面后点「连接设备」，在系统弹窗里选中手柄，读取完成后即可调参。没有手柄时可以点「模拟设备」：它顶替 `navigator.hid`，按同一套协议收发，并且真的校验帧校验与 CRC，写入落在本地存储，刷新后仍在。

## 界面

| 页面 | 内容 |
|---|---|
| 状态 | 连接信息、设备字段摘要、未写入改动、操作日志 |
| 按键映射 | 键位槽列表与输出类型（按键、组合、宏） |
| 摇杆 | 径向曲线 5 断点（可拖动）、死区、轴反转；带试推与手柄实读 |
| 扳机 | 左右行程上下限、微动（hire）模式、输出曲线 |
| 体感 | 模拟左/右摇杆、常开或按键触发、触发按键、轴向反转 |
| 震动 | 档位与左右马达参数（只写参数，不触发震动） |
| 调试 | 508 字节逐字节对照、改动高亮、差异表 |
| 备份 | 整份配置导出 / 导入、恢复出厂 |

顶栏的「自动写入」勾选后，改动会防抖写盘，写入按钮置灰；不勾选则先弹确认。字段偏移、公式推导一类注解默认隐藏，在「关于 → 显示字段注解」里打开。

## 协议要点

- 载荷 508 字节，`[0..1]` 是 CRC-16/MODBUS（覆盖 `[2..507]`）
- 传输按 64 字节报告分块，每轮 9 帧（8 × 59B + 末块 36B），帧校验为数据字节求和 mod 256
- 读取：发 `a5 04 d6 7f`，设备回 9 帧重组
- 摇杆曲线作用于**径向模长**：先算推杆距离，过死区后分段线性查表，方向保持不变
- 扳机输出 `clamp((R - low) / (high - low) × 255)`，微动模式下变二值

完整字段表见 [`docs/508B-field-map.md`](docs/508B-field-map.md)，含每个字节的来源、默认值、是否真机验证。

## 已知限制

- 体感页的 `gyro_sens`、`h2v_ratio`、`resp_curve`、`deadzone_comp` 四个参数写入后能落盘，但本固件不消费，所以界面上没有对应滑块
- 「模拟左摇杆 / 模拟右摇杆」两种模式均已真机验证；`[311]` 的轴向反转位随模式切换（mode 1 用 bit1/bit2，mode 2 用 bit3/bit4），其中 mode 2 的反转位只验证到写入与读回一致
- `[361..376]` 写入与读回的字节序相反（每次写翻转一次），界面不做该区间的编辑，原样回传
- `[309..310]`、`[319..343]`、`[348]` 等区间能落盘但语义未定，未在界面开放
- 部分取值会让设备掉线重枚举，写入前后请保留一份备份

## 安全

本项目只做配置读写，不包含也不支持固件升级。写入前建议先读取当前配置并导出备份；如遇异常，用备份页导入回滚。使用风险自负。
